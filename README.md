# Modular Table Blocks

WordPressのブロックエディターで、セルごとに文章・画像・リストなどを配置できるテーブルを作成するプラグインです。行・列の編集、セルの結合、装飾の一括設定、CSVやコピーした表の取り込みに対応しています。

## できること

- セル内へ文字や画像、見出し、リスト、ボタンを配置する。
- 行・列を追加・削除・複製・移動する。
- 複数セルを結合し、必要に応じて分割する。
- 見出しセル、キャプション、表幅、列幅、横スクロールを設定する。
- 色・文字・罫線・余白・位置揃えを、セル単位または複数行・列へまとめて設定する。
- 見出しの背景色や、行・列ごとのストライプを設定する。
- コピーした表やCSVテキストから新しい表を作り、既存の表へ取り込む。

## 導入方法

### 動作環境

- WordPress 6.6以上
- PHP 7.4以上
- WordPressのブロックエディター

導入には、ビルド済みファイルを含む配布用ZIP、またはプラグイン一式を使用してください。

### ZIPファイルから導入する場合

1. WordPressの管理画面で「プラグイン → 新規プラグインを追加」を開きます。
2. 「プラグインのアップロード」からプラグインのZIPファイルを選びます。
3. 「今すぐインストール」を押し、完了後に有効化します。

### フォルダーを配置する場合

1. プラグイン一式のフォルダーを`wp-content/plugins/modular-table-blocks`へ配置します。
2. フォルダー直下に`modular-table-blocks.php`があることを確認します。
3. WordPressの「プラグイン」画面で「Modular Table Blocks」を有効化します。

日本語で利用する場合は、「設定 → 一般 → サイトの言語」、またはユーザーのプロフィールの言語を「日本語」にします。日本語以外で対応する翻訳がない場合は英語で表示します。

### 更新する

有効化中は作者の配信サーバーへ更新情報を問い合わせます。新しい版が配信されると、WordPress標準の「プラグイン」または「ダッシュボード → 更新」から更新できます。自動更新はプラグイン一覧で有効・無効を選べます。配信サーバーに接続できない場合、更新情報を取得できません。停止中は更新情報の問い合わせも停止します。

更新機能を持たない旧版からは、最初の1回だけ新しい配布用ZIPを「プラグインのアップロード」から送り、既存版との置き換えを選んでください。以後は管理画面から更新できます。更新時にプラグインを削除する必要はありません。

## 表を作成する

1. 投稿や固定ページの編集画面で「モジュラーテーブル」ブロックを追加します。
2. 行数と列数を指定します。初期値は3行×3列で、作成時はそれぞれ1〜20を指定できます。
3. 「テーブルを作成」を押します。
4. セル内をクリックして文字を入力します。

作成後は行・列を追加して、最大100行×50列まで拡張できます。セルを選びにくい場合は、エディターのリストビューから選択してください。

## セルに内容を入れる

新しいセルには、空の「セルテキスト」が1つ入っています。文字と改行を入力でき、ツールバーで太字・斜体・リンクなどの書式を設定できます。文字の色・サイズ・位置揃えは、セルまたはテーブル側で設定します。

画像やリストなどを使う場合は、セルテキストを選択し、ブロックの変換から「段落」へ置き換えます。入力済みの文字・改行・書式を引き継ぎます。セルテキストを削除し、通常のブロック追加ボタンから使いたいブロックを選ぶこともできます。

| 構成 | 配置できる内容 |
| --- | --- |
| セルテキスト | 1セルにつき1つ。他のブロックとは併用しません。 |
| 通常のブロック | 段落・リスト・見出し・画像・ボタンを組み合わせて配置できます。 |

セルテキストを削除した後や、すでに通常のブロックがあるセルへ、セルテキストを自動で追加することはありません。

内容の混在を知らせる警告が出た場合は、セルテキストを段落へ変換するか、不要なブロックを削除して整理してください。

## テーブルとセルの設定

表全体の設定はテーブルブロック、個別の設定はセルブロックを選択して行います。

| 選択するブロック | 設定の場所 | 主な設定 |
| --- | --- | --- |
| テーブル | 「設定」タブの「テーブル設定」 | 見出し行、横スクロール、セルの一括設定、列幅、セル間隔、テーブルの幅、キャプション |
| テーブル | 「スタイル」タブ | 背景色、文字色、タイポグラフィー、外側余白、最小高さ、見出し・ストライプの背景色 |
| セル | 「設定」タブ | データセル（TD）／見出しセル（TH）、見出しの関連付け |
| セル | 「スタイル」タブ | 背景、タイポグラフィー、位置揃え、罫線、内側余白 |

タイポグラフィーでは、文字サイズ・書体・太さ・斜体・行間・字間・文字装飾などを設定できます。表示される項目や候補は、WordPressとテーマの設定に従います。

### 見出し行と見出しセル

「先頭行を見出しにする（TH）」をオンにすると、先頭行を見出し行にします。その行のセルの種類・関連付けはテーブルから管理され、セル側では変更できません。行を移動した場合も、その時点の先頭行が見出し行になります。

オフにすると先頭行をデータセル（TD）へ戻し、関連付けを解除します。以前の個別設定を復元したい場合は、エディターの「元に戻す」を使ってください。先頭行以外は、セル設定の「データセル（TD）」「見出しセル（TH）」で切り替えます。

### 列幅とテーブルの幅

| モード | 表示 |
| --- | --- |
| 均等幅 | 各列の幅を均等にします。新しい表の初期設定です。 |
| 自動幅 | セルの内容に応じて列幅を調整します。 |
| 幅指定 | 列ごとに幅を入力します。空欄の初期単位は％です。 |

入力済みの列幅はモードを切り替えても保持します。指定を解除する場合は数値欄を空にしてください。表全体の幅は「テーブルの幅」で設定します。

幅の広い表は「横スクロール」を有効にすると、狭い画面でも左右へスクロールできます。スクロール領域へフォーカスを移し、左右キーで操作することもできます。

### 罫線・余白・セル間隔

セルの罫線は色・種類・太さを指定できます。線種の初期表示は実線です。罫線と内側余白は、全方向をまとめて設定するか、上下左右を分けて設定できます。単位は数値欄の中で切り替えます。

「セル間隔」では、罫線を「重ねる」「分離する」から選びます。初期設定は「重ねる」です。「分離する」ではセル間の間隔を指定でき、横・縦をまとめるか個別に設定するかを切り替えられます。「重ねる」へ戻しても、入力した間隔は保持します。

罫線を重ねる場合は、隣り合うセルの線が1本として表示されます。一方の線幅を0にしても、隣のセルに設定された線が残ることがあります。

### 背景色とストライプ

テーブルの背景色を基本色にして、「見出し背景色（TH）」や「データセルのストライプ（TD）」を重ねられます。テーマに登録されたパレットの色も利用できます。

- 行ストライプは、見出し行を除いた本文の2・4…行へ適用します。
- 列ストライプは、表全体の2・4…列へ適用します。
- 見出しセル（TH）はストライプの対象外です。
- 結合セルは左上の位置でストライプを判定します。

セルごとに指定した背景色を最優先します。パレットの「クリア」で個別色を解除すると、その位置の見出し色・ストライプなどへ戻ります。ストライプの方向を切り替えても、選択済みの色は保持します。

### 位置揃えと設定の解除

「位置揃え」では9方向のボタンから垂直・水平の揃え方をまとめて指定します。同じ位置をもう一度押すと解除し、テーブルの設定を引き継ぎます。位置の説明はツールチップで確認できます。矢印キーで移動し、Enter／Spaceで選ぶこともできます。

色のパレットは「テーマ」「デフォルト」「カスタム」に分けて表示します。表示されるカテゴリと色は、テーマやサイトの設定によって異なります。

個別の色はパレットの「クリア」、数値は空欄や設定メニューのリセットで解除します。セル内の段落・見出しなどで個別に指定した装飾は、そのブロック側で変更してください。

列幅・セル間隔・テーブルの幅・キャプションは、各見出しの3点メニューからその設定だけをリセットできます。列幅は均等幅、セル間隔は罫線を重ねる状態、テーブルの幅は未指定へ戻ります。キャプションは本文を残して非表示にし、配置と文字揃えを初期状態へ戻します。

### キャプション

「キャプションを表示」をオンにすると、表の上または下で表題を直接入力できます。設定から上下の配置と文字揃えを選べます。太字・斜体・リンクも使用できます。

非表示にしても本文や配置は保持します。本文が空のキャプションは、公開ページには表示しません。

## 行・列を編集する

セルを選択し、ブロックツールバーから操作します。

| メニュー | 操作 |
| --- | --- |
| テーブルの構造 | 選択した位置の前後へ行・列を挿入し、複製・削除します。複製した列は右隣へ追加します。 |
| 行・列の移動 | 行を上下、列を左右へ1つずつ移動します。 |

表を選択している場合、「テーブルの構造」には末尾への行・列追加を表示します。移動・複製ではセル内の内容と設定を引き継ぎます。内容がある行・列の削除では確認画面を表示し、キャンセルできます。

行を挿入すると、起点行の各列の装飾を引き継ぎます。列の挿入では、起点列の各行の装飾と列幅を引き継ぎます。TH／TDの種類と、THの見出しの関連付けも引き継ぎます。末尾へ追加する場合は、最後の行・列が起点です。新しいセルの本文は空で、ロック・結合形状は複製しません。表から継承している装飾は、そのまま継承します。「先頭行を見出しにする（TH）」の対象行では、表の設定を優先します。

結合を分断するなど、安全に処理できない操作は無効になります。対象の結合セルを分割してから操作してください。構造の変更は1回の「元に戻す」で戻せます。

## セルを結合・分割する

1. 結合範囲の左上になるセルを選びます。
2. ツールバーの「セルの結合・分割」ボタンを押します。
3. 表のプレビューで結合範囲の終点セルを選びます。
4. 「セルを結合」を押します。内容の削除確認が出た場合は、対象を確認して承認します。

結合後に残るのは左上のセルの内容と設定です。**承認すると、それ以外の対象セルの内容は、ロックされたブロックを含めて削除します。** 空のセルテキストなど、空に見えるブロックも確認対象になります。

未結合セルで結合できる範囲がない場合は、ボタンが無効になります。既存の結合セルの一部だけを含む範囲や、見出し行と本文をまたぐ範囲は選べません。先頭行をまたぐ結合がある場合は、分割してから見出し行を有効にしてください。プレビューはTabで入り、矢印キーとEnter／Spaceでも終点を選べます。

結合セルを選ぶと「セルの結合・分割」ボタンが反転表示になります。もう一度押すと分割し、通常の表示に戻ります。分割時はメニューやモーダルを開きません。内容は左上に残り、追加したセルには空のセルテキストが入ります。分割では削除済みの内容は復元しません。結合・削除の直後なら「元に戻す」で内容も戻せます。

結合の内側へ行・列を挿入すると結合範囲を広げ、重なる行・列を削除すると範囲を縮めます。縦方向の結合に影響する行の移動・複製と、横方向の結合に影響する列の移動・複製は、分割してから操作してください。

## セルを一括設定する

1. テーブルを選択し、「テーブル設定」の「セルの一括設定」を開きます。
2. 左側の「セルの選択」で対象の全セル・行・列を選びます。
3. 右側で変更したい項目を設定します。
4. 「適用」を押します。画面は開いたままなので、続けて別の範囲を設定できます。

### 対象の選び方

| 押す場所 | 選択対象 |
| --- | --- |
| プレビュー左上 | 全セル。全選択中にもう一度押すと解除します。 |
| 行番号 | 行全体。複数の行を選べます。 |
| 列番号 | 列全体。複数の列を選べます。 |

開いた直後は未選択です。同じ行番号・列番号をもう一度押すと解除します。離れた行・列も選べますが、全セル・行・列を同時に選ぶことはできません。TabとEnter／Spaceでも選択できます。

プレビューには現在の装飾と入力途中の変更を反映します。TH／TDの表示でセルの種類を確認できます。内容は位置を示すサンプルです。選択中のセル数は選択欄の下端に表示し、表が領域に収まらない場合は、公開表の横スクロール設定に関係なく、プレビュー内を縦・横にスクロールできます。狭い画面では選択欄と設定欄を上下に並べます。

### 設定できる項目とリセット

セルの種類、位置揃え、背景、罫線、余白、タイポグラフィーを設定できます。列幅はテーブルの「列幅」で変更してください。先頭の見出し行は、ここでセルの種類を変更できません。

タイポグラフィーは文字色とフォントサイズを初期表示します。見出しの3点メニューから書体・外観・行間・字間・文字装飾などの表示を切り替えられます。項目を隠しても入力途中の値は保持します。

各見出しの3点メニューでリセットできます。「セルの種類」は選択範囲の種類の変更を取り消し、ほかのパネルは選択範囲の該当設定を解除します。タイポグラフィーの「すべてリセット」は非表示項目も対象です。全項目を非表示にした場合は、1項目を再表示してから操作してください。

### 適用と変更の保持

選択を切り替えたり解除したりしても、入力した変更は残ります。たとえば1行目の文字サイズと2列目の余白を続けて設定し、最後にまとめて適用できます。同じ項目を重ねて変更すると、後の入力を優先します。

「適用」は現在の選択だけでなく、その画面で行った未適用の変更すべてを反映します。適用ごとに1回の「元に戻す」で戻せます。「閉じる」・×・Escapeでは、未適用の変更だけを破棄し、適用済みの変更は残します。

表全体の設定は、後から追加するセルも引き継ぎます。一部の行・列だけの設定は、その時点の対象セルへ適用します。たとえば各行の文字サイズを順に変更して全セルが同じサイズになった場合も、追加セルはそのサイズを引き継ぎます。表の構造や列設定が途中で変わった場合は、画面を開き直してください。

### 結合セルを含む場合

選択した行・列の範囲を、結合セルに合わせて広げることはありません。罫線・余白は、辺全体が選択範囲内に収まる場合だけ変更します。たとえば1〜2列を結合したセルで2列目だけを選ぶと、右辺は変更できますが、左辺と上下辺は保持します。

背景・タイポグラフィー・位置揃え・セルの種類は、選択範囲と一部でも重なる結合セル全体へ反映します。結合セルの途中に罫線を追加したり、辺の一部分だけを変更したりすることはできません。

## データを取り込む

表の作成画面、またはテーブル・セルのツールバーの「データを取り込む」から開きます。ExcelやGoogleスプレッドシートなどでコピーした表、タブ区切りテキスト、CSVテキストを貼り付けられます。CSVを直接入力することもできます。ファイルのアップロードには対応していません。

1. 入力欄へデータを貼り付けます。形式は自動判定し、必要ならカンマ・タブ・セミコロン・HTMLを選び直せます。
2. 既存の表から開いた場合は、「現在の表」「新しい表」を選びます。
3. 現在の表へ取り込む場合は、プレビューで起点セルを選びます。
4. 取り込み後のプレビューを確認し、既存内容を置き換える場合は確認にチェックします。
5. 「取り込む」を押します。

「現在の表」は、テーブルを選択して開くと左上、セルを選択して開くとそのセルを初期起点にします。足りない行・列は下・右へ追加し、確定ボタンに最終サイズを表示します。小さい範囲を取り込んでも、残りのセルは削除しません。「新しい表」は現在の表の直後へ独立した表を作成します。

既存のセルの種類・装飾・結合、表の背景・列幅・キャプションは保持します。**置き換えるセルの内容は、画像やその他のブロックを含めてセルテキストへ置き換えます。** ロックされた対象へは取り込めません。キャンセルでは表を変更せず、確定後は1回の「元に戻す」で拡張と内容をまとめて戻せます。セル内へ直接貼り付ける通常の編集操作は変わりません。

### 取り込む値と見出し

先頭ゼロ・大きい数値・日付・式は文字列のまま保持し、計算は行いません。引用符内のカンマ・改行・二重引用符にも対応します。明示的な空欄は内容を消去しますが、短い行の欠けた項目は警告し、その位置の既存内容を保持します。

新規のCSV・タブ区切りでは、先頭行を見出し（TH）にする設定を選べます。HTMLの表は見出しと結合形状を引き継ぎますが、装飾・画像・キャプション・列幅は引き継ぎません。

### 結合セルと取り込み上限

既存表へ複数の値を取り込む場合は、結合形状が完全に一致する必要があります。結合セルと一部だけ重なる範囲や、結合のないCSVで結合範囲を上書きする操作は拒否します。単一の値なら、結合を保って内容だけを変更できます。拡張部分へ新しい結合を作りたい場合は、新しい表として取り込んでください。

上限は100行×50列、元入力100万文字・本文20万文字です。超過時は切り捨てずに取り込みを中止します。大量のセルではプレビューや編集画面の描画に時間がかかります。取り込み元のアプリや環境によってコピー結果が異なるため、確定前にプレビューを確認してください。

## 利用上の注意

- 文字の装飾・色・余白など、選べる設定や候補はWordPressとテーマによって異なります。
- 編集画面と公開ページでは、自動調整した列幅や罫線の重なりが完全には一致しない場合があります。公開前に表示を確認してください。
- 一括設定を開いたまま画面を狭くすると、番号の選択時にモーダルの見出しが画面外へ動く場合があります。画面幅の変更は、一括設定を閉じてから行ってください。
- 表計算、並べ替え・絞り込み、表の入れ子、ドラッグによるセル範囲選択には対応していません。
- WordPress 6.6では、投稿者権限で段落に保存した数値文字参照（例：`&#65;`）が文字（例：`A`）へ変わる場合があります。そのまま残したい場合はセルテキストを利用してください。
- WordPress 6.6で位置揃えのツールチップが操作対象へ重なる場合は、Escapeで閉じてから選択してください。
- リストビューから編集へ戻った際に本文へ入力できない場合は、セル枠をクリックしてから本文を選んでください。
- 「表のグリッドが不整合です」と表示された場合は、行・列の操作を中止します。内容を確認し、必要に応じて新しい表へ移してください。
