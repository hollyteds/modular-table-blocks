# M0：編集DOM・保存形式・スタイルの継承

## 採用する構成

編集画面はdiv/CSS Grid、公開画面はルートブロックのPHP動的レンダラーを使用する。テーブル・行・セルはすべて `InnerBlocks.Content` だけを保存し、子ブロックのコメントと本文を維持する。`save: () => null` は子ブロックを失うためこの階層には使用しない。

ルートの `skip_inner_blocks` で自動的な子の描画を止め、行・セルを走査して本文の `WP_Block::render()` を1回だけ呼ぶ。行・セル単独のレンダラーは空文字を返す。PHPテストで本文フィルターの呼び出し回数を検証する。

## エディターDOMの比較

Playwrightの試作ブロックで、`table` + `tbody` のInnerBlocks、`tr` の行ラッパー、`td` のセルラッパーを登録して2×2で挿入する。標準の追加UIを有効にすると、`tbody` 直下に `tr` 以外の要素が生成されることを実DOMで確認した。テストは `semantic-editor-dom.html` を添付する。

この結果は「意味的ラッパーがどの構成でも不可能」という判断ではない。追加UIを抑えた限定構成や将来のGutenbergでは成立する可能性がある。M1の構造操作へ拡張する際の制約を避けるため、編集画面はdivを採用する。通常のGutenbergの `role="document"` と操作名を維持し、ARIAのtable/gridロールは追加しない。

採用構成ではセルが行divの直下に存在すること、保存HTMLに編集クラスが混入しないこと、再読み込み後の入れ子を含むブロック検証が成功することを確認する。意味的試作での保存復元やドラッグ操作の比較は未実施。

## スタイル方針の変更

更新された設計に従い、文字色・背景色・罫線・セル余白・文字サイズ・行間・テーブル幅を `--mtb-*` に統一する。共通Sass mixinを編集と公開の両方から使用する。既定トークンをローカルに宣言せず、`var()` のフォールバックだけを持つ。

行・セルは自分自身で文字色・文字サイズ・行間を参照する。セルの罫線・余白・背景もセル要素で参照するため、個別セルの変数が反映される。公開CSSは `:where()` を使用し、テーマからの上書きを妨げる詳細度の上昇を避ける。編集UIの枠線やフォーカス装飾は別CSSとする。

公開CSSの詳細度と余白の重要指定は、後続の[テーマとの優先関係の判断](0004-public-theme-styles.md)で変更した。トークンの継承と保存形式は維持する。

`styleTokens` は明示設定時のみ保存する。空オブジェクトの既定値はPHPメタデータ経由で配列に変換されるため、属性スキーマに既定値を置かない。空欄へ戻すと該当キーを削除し、ラッパーからそのカスタムプロパティを除去する。TypeScriptとPHPの検証は共通fixtureで照合する。

色・長さ・罫線種類・行間に許可範囲を設け、WordPressのプリセット参照は限定した文法のみ許可する。theme.jsonのプリセット・コア本文の明示設定とは通常の継承とカスケードで共存する。任意のCSS文字列は属性から直接出力しない。

## 検証範囲

- ビルド、TypeScript型検査、ESLint、SassのStylelint。
- 単体テスト50件：占有状態・重複・範囲外・空白・入力非破壊性、CSS値の許可／拒否。
- PHP：3ブロックの登録、描画回数、キャプションのエスケープ、見出し、HTML階層、ブロックツリーの往復、同じfixtureでのCSS値検証。
- Playwright：2×2の内容・キーボード編集、保存復元、公開HTML、複数テーブル、サイト→テーブル→行→セルの継承、テーマ変更、設定UIの検証・保存・解除、狭幅でのtable-cell維持、意味的DOMの試作比較。

リストビュー等の網羅的操作検証と支援技術による操作確認は残る。M0通過とMVP全体の完了は区別する。

再読み込み後のエディターのスクリーンショットも確認した。保存復元後に全階層の `isValid` と再シリアライズの一致を検証し、公開HTMLには編集用ラッパーが含まれない。WordPress 6.6の開発モードでは、コアのReact `createRoot` 警告が発生するため完全一致で注記する。ブロックの重複登録エラーは共通スクリプトハンドルへの変更で解消した。

テスト環境は独立したwp-envコンテナーを使用し、既存の別サイトのコンテナーは変更していない。開発依存のインストールでengine・audit警告が残ることはREADMEに記載した。
